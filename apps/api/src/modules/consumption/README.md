# Модуль щоденника споживання

Модуль будує денний щоденник і періодний dashboard на межі плану й факту. Приготований
`MealEntryParticipant` є лише кандидатом `PENDING`: до встановлення чекбокса
`ConsumptionEntry` не створюється.

## Lifecycle

- confirm створює факт `CONFIRMED`, nutrient snapshot і resolution;
- зміна грамів або прийому їжі збільшує `revision`, перераховує snapshot і
  переводить resolution у `CHANGED`, якщо факт відрізняється від плану;
- скасування чекбокса анулює факт через `VOIDED`, а resolution переводить у
  `UNCONFIRMED` із `consumptionEntryId = null`; це не означає пропуск;
- окрема дія «Пропустити» переводить resolution у `SKIPPED`; «Відновити»
  повертає позицію до `UNCONFIRMED`, після чого її можна знову підтвердити;
- повторне встановлення чекбокса відновлює анульований факт зі збереженою
  фактичною порцією, яку після цього можна змінити;
- ручний запис має source `MANUAL`, прийом їжі, рівно один `Product` або
  `Recipe` і не змінює план.

Snapshot використовує completed `CookingSession` як пріоритетне джерело,
інакше — канонічні нутрієнти продукту або рецепта. До snapshot потрапляють лише
активні базові або цільові нутрієнти, дозволені DB whitelist. Агрегати включають
лише активні `CONFIRMED` facts.

Dashboard приймає явний набір із 1–31 локальної дати. Це підтримує повний
календарний тиждень, місяць і довільний вибір дат у межах тижня без
припущення про суцільність періоду. Персональні цілі масштабуються за кількістю
вибраних днів, а вага показується на початок і кінець періоду за останніми
відомими вимірюваннями.

## Доступ

Active family завжди визначає сервер. `OWNER` читає й змінює щоденники всіх
активних профілів своєї сім’ї. `MEMBER` отримує й змінює лише профіль,
пов’язаний із власним `User`. Глобальна роль application administrator не
розширює family access.

## Перевірка

```text
npm run typecheck -w @mealmind/api
npm test -w @mealmind/api
npm run api:test:consumption:db
```

PostgreSQL integration test запускається лише після `npm run db:test` і лише
проти локальної ізольованої бази `mealmind_test` на `127.0.0.1:54322`.
