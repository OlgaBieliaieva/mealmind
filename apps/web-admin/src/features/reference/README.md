# Адміністрування довідників

Маршрути /reference/:resource надають адміністратору єдиний CRUD-інтерфейс для
десяти каталогів reference-модуля. Конфігурація полів централізована в
reference-config.ts, але серверний Zod-контракт залишається остаточним джерелом
валідації.

Видалення завжди є soft delete. Звичайні довідники отримують isActive=false,
автори архівуються, а бренди переходять у ARCHIVED. Це захищає зв’язки з
продуктами, рецептами й історичними даними. Архівні значення доступні через
фільтр і можуть бути відновлені.

UI підтримує пошук, пагінацію, ієрархічне відображення категорій, create/edit
форми, підтвердження архівації, loading/error/empty/success states та повторне
оновлення option queries, які використовують форми продуктів і рецептів.
