# Onboarding і сімейний контекст у web-client

Маршрут /onboarding містить покрокову форму «одне питання — один екран». Стан відповідей існує лише в пам’яті компонента й надсилається одним атомарним запитом на останньому кроці. Оновлення сторінки, вихід або переривання процесу очищує чернетку, тому наступний вхід починається з першого питання.

Кожен крок пояснює мету використання даних. Обов’язковим для мінімального профілю є лише ім’я; прізвище й персоналізацію можна пропустити. Progress bar, keyboard navigation, доступні labels і недвозначні error states є частиною контракту UI.

Next.js Proxy після refresh Supabase session виконує idempotent account bootstrap і читає application session. Незавершений користувач перенаправляється на /onboarding, а завершений не може повторно відкрити onboarding. /family дозволяє OWNER змінити назву сім’ї та створювати, редагувати й архівувати dependent-профілі.
