# Onboarding і сімейний контекст у web-client

Маршрут /onboarding містить покрокову форму «одне питання — один екран». Стан відповідей існує лише в пам’яті компонента й надсилається одним атомарним запитом на останньому кроці. Оновлення сторінки, вихід або переривання процесу очищує чернетку, тому наступний вхід починається з першого питання.

Кожен крок пояснює мету використання даних. Обов’язковим для мінімального профілю є лише ім’я; прізвище й персоналізацію можна пропустити. Для автоматичного розрахунку базових норм користувач має добровільно надати дату народження, стать для розрахунків, зріст, вагу та рівень активності. Чинна policy підтримує лише профілі віком від 18 років.

Після фінального submit API атомарно завершує onboarding. Для eligible профілю web-client показує короткий екран очікування з доступним progress від 0 до 100%, після чого читає створений `NutrientTargetSet` через `/api/v1/profile/me` та відображає:

- енергію у стані спокою;
- енергію з урахуванням рівня активності;
- рекомендовані діапазони білків, вуглеводів і жирів.

Progress є UI-індикатором очікування, а не server-reported відсотком виконання: backend calculation залишається короткою атомарною операцією і не публікує проміжні результати. Значення показуються лише після успішного response та читання persisted snapshot.

Якщо даних недостатньо, стать має значення `UNSPECIFIED` або користувачу ще немає 18 років, onboarding однаково завершується. Фінальний екран пояснює, що дані можна доповнити в особистому профілі та запустити розрахунок пізніше. Кнопка «Розпочати» завершує presentation flow і переводить користувача до застосунку.

Progress bar кроків і розрахунку, keyboard navigation, доступні labels, live status та недвозначні error states є частиною контракту UI. Анімація враховує `prefers-reduced-motion`.

Next.js Proxy після refresh Supabase session виконує idempotent account bootstrap і читає application session. Незавершений користувач перенаправляється на /onboarding, а завершений не може повторно відкрити onboarding. /family дозволяє OWNER змінити назву сім’ї та створювати, редагувати й архівувати dependent-профілі.
